| Раскладка | контент 1320, поля 24 (моб. 16), отступ секции `fluid(20,104)` |
| Радиусы / тени | pill 999, карточка 24/26, плитка 14, поле 12; `--sh-btn`, `--sh-float`, `--sh-seg` |
| Мозаика | SCSS-список `$mosaic` (9 цветов eyebrow-маркера) |

Конфликты с темой (решить на этапе 2):
- `_var.scss` задаёт `--container: 1360px` и `--section-y: 60px`; токены идут позже и перекрывают (1320 / fluid 20–104).
- `.container` темы — `max-width: 1640px; padding: 0 100px`, макет — 1368 с полями 24/16. Для лендинга по макету `.container` переопределить.
- Отступ секции в макете переключается на 980px скачком (104 → 20); `fluid(20,104)` даёт плавный переход, на 390 и 1440 значения совпадают с макетом.
- Заголовки темы `font-weight: 500`, `Montserrat` на body; в макете h1/h2 — Montserrat 800, `letter-spacing: -0.02em`, `line-height: 1.06–1.08`, тело — Open Sans 16/1.5.

## Особенности стартовой темы

- Брейкпоинт темы `$bp-mobile: 860px`, `$bp-small: 600px`; **в макете единственный брейкпоинт 980px** → решить на этапе 1 (по умолчанию: заменить на 980).
- Есть `fluid($min,$max,$minVp=390,$maxVp=1440)`, `theme_image()`, `theme_opt()`, `theme_logo()`, `.container` через `--container: 1360px`.
- SCSS: `@import`, `assets/scss/{common,modules,pages}`; сборка `npm run build` (sass → assets/css/style.min.css), JS: `assets/js/app.js`.
- Шрифты: Montserrat self-host есть; **Open Sans нужно добавить** (макет: Montserrat 500–800 + Open Sans 400/600/700).
- `SETUP.md` и `htaccess.txt` удалить в конце проекта.
